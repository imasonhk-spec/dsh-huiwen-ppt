# 汇文 PPT 0.5.0

DSH 工作台插件。项目、材料、大纲、模板计划、PPTX、预览、版本、批注与导出均通过真实后端保存；模型失败时报告原因，不生成替代内容。

当前组件生产使用包内固定资源`resources/huiwen-ppt/`：绿色简洁商务41页、绿色办公插画14页，账号可变组件库存于其dataDir。选模板后创建携带固定选择的新对话；发送要求或材料后连续生成全稿，上传本身不生成。默认不要求需求、大纲和样张审批，只有显式请求才先交大纲或样张。页数遵循用户要求，8–12仅为建议，真实构建契约1–500页。

默认自动生成由文本模型整理材料、大纲和页面关系，再选择宿主提供的完整来源候选。宿主按实际原生容量分配原文、确定组件与位置，并先实际编译候选；模型只返回候选ID。原文不截断、不补造事实，没有合法候选时明确失败；图表只使用来源支持的数据，模板示例不作为业务事实。人工组件调整、锁定和局部修改仍按原修订机制执行。

画布与对话共用组件修订，支持节点内容/排列、组内绑定、组件几何、组件/区域锁与局部修改。旧SHA、旧组件修订号、锁冲突及混合批次失败均不提交版本；外部保存须重导入。失败或断连按原job_id对账。

Host以`non_visual_v1`核验结构、绑定、来源、确定性布局、真实渲染及“OOXML编辑＋LibreOffice保存重开”。ready只表示本期可下载；模型看图、视觉构图理解、成稿视觉评审和AI生图均暂停，原skill QA保持实际review_required，不能凭非视觉报告晋级。上线前WPS打开/修改/保存重开由用户真实执行，未回结果前保持待验收；PowerPoint未测。

本候选尚须按工作区设计的32项验收及8任务计划交付，实际证据和未测边界见`release/`。全账号发布仅清核实属于汇文的历史，保留认证/许可/模型配置、其他应用、共享原件、Desktop输入及设计/交接。软件回滚不恢复已经删除的历史，也不得覆盖上线后新数据。

## 历史原页填充版本说明

0.4.9 对正文不足的页面只扩写有足够余量的一个正文区，按实际字数缺口给出该区最低字数；其余字段保留，并共同校验整页、真实容量、原文证据和大纲技术名称。若模型少算字，保留已通过容量与事实检查的有效增长，再补实际剩余缺口；只有最终整页达标才保存为合格正文。避免让模型重写全部字段后仍返回相同的不足正文。

0.4.8 将保守写作目标与真实排版容量分开：按文本框可读行列数估算写作预算，文本框硬校验使用实际字宽与折行（英文不按汉字宽度计算），目标字数保留余量；初稿先校验证据和字段，正文不足交给专门补充流程，窄字段连续压缩失败时改为整页重新分配长实体与正文，补充/重新分配后再次压缩溢出字段，最终同时校验容量、丰富度、原文依据与要点，补充和压缩必须保留原文支持且大纲明确要求的英文技术名称，不截断正文、不放宽实际排版校验。

0.4.7 修正正文容量计算：读取原生文本框边距，保留零边距，校验与实际 PPTX 写入使用一致的可用尺寸，按实际面积计算字数预算，取消短文本框固定 44 字上限。旧模板巡检在项目内补充，不改批准模板原件；无法容纳可读文字的字段提前报告版式错误，真实溢出仍需模型精简；压缩后正文不足时按原文补充，并同时校验容量、丰富度、要点与证据。

0.4.6 将上传图片保留为版式参考，不执行正文提取或作为事实证据；既有图片直接兼容，无需迁移材料文件。需求、大纲、逐页正文与知识分析仅校验正文材料；文档解析失败仍如实报错。页面提供原图查看链接并明确参考用途。

0.4.5 修复附件选择后清空文件列表导致未发起上传的问题；材料上传、PPT 导入和模板上传统一使用已经解码的查询参数，保留文件名中的 %。

0.4.4 在生成前要求明确确认模板主题与页数，直接生成和 API 调用使用相同要求。在所选主题内按内容关系分配不同版式，保留用户明确选择。新增真实模型逐页正文生成，完整填充分区标题、正文和表格，并按实际字段容量校验；不再用大纲的规划目的充当正文。不提供真实统计序列的页面以可编辑文字说明数据与口径，避免展示模板的演示图表。内容失败或取消不提交版本；合格正文按材料、需求、页面和模型缓存，变更后重新生成。材料充分且未指定页数时建议12页，确认模板时可调整。

保留0.4.3的真实模型证据编号、2048 tokens批次限制、结构化输出纠正、状态恢复及真实修改/回滚/导出功能。服务器渲染使用LibreOffice；Windows/WPS原生渲染仍需外部渲染服务。

## 使用

新建对话或导入PPTX，可补充材料、修改需求、选模板和生成。默认组件制作一次全稿，支持1–500页；显式原页填充保留其已有草稿/定稿语义。

画布支持原生文字、表格单元格、位置/尺寸/旋转、对象删除、文字与 PNG/SVG 素材插入、修改队列撤销/重做、批注、实际版本比较及回滚。每次保存产生新版本，过期版本或 SHA 请求返回冲突。

导出创建独立文件；组件稿检查通过后以ready交付，保持活动项目。原页填充按其已有定稿语义归档。历史导出独立下载，项目删除清理项目和关联导出。

## 运行依赖

- DSH 宿主提供 React 与插件加载协议；Node 需支持 fetch、AbortSignal.any。
- Python 3；包内 server/scripts/studio.py 处理真实 OOXML 构建与编辑。
- LibreOffice、pdftoppm、pdftotext 提供服务器渲染及 PDF 正文提取。
- 固定模板与组件执行资源：包内resources/huiwen-ppt；不执行Desktop输入，不接受旧config的skillDir覆盖。
- Ollama 或 DSH 已登记模型。材料分块摘要、大纲、自然语言修订与事实提取需要可用真实模型。
- 多用户业务目录由HUIWEN_DATA_DIR绑定当前账号；隔离测试使用独立目录。

## 实际边界

扫描 PDF 不执行 OCR，会明确显示需要 OCR；不适配的图表和表格示例在生成时移除，业务要点保留为原生文字。全页图片遮挡下的对象不能直接修改。结构与 PNG 完整性通过不代表人工视觉验收通过。

Windows WPS/PowerPoint 服务可在首页配置地址、令牌和引擎；使用已有 /health、/render 协议。远端不可用时如实失败。该版本验证了协议故障路径，尚未在实际 Windows COM 引擎验收；本地取消会停止等待并阻止提交，既有远端服务不能远程中止已开始的 COM 操作。

# 风格分支：绿色办公插画

用户于 2026-10-08 明确要求：“把这一套插画风格的样式保存在ppt-studio 技能里面，设置为默认的风格”。长期保存已确认。随后同日用户完成新风格访谈，选择新建时推荐并确认风格；早先的自动默认选择已被该决定替代。来源为 AI + NAS 应用场景分析会插画风格 v5；授权记录及文件校验值见 `../assets/default-illustrated/manifest.json`。

## 使用范围

用户选定绿色办公插画分支后采用；未指定时遵循 [风格选择与融合](style-selection.md)。用户指定的模板、品牌、风格和页面修改范围优先。视觉复用授权涵盖版式、配色、字体、插画与背景的复用；参考稿中的主题、单位现状和模拟案例按新任务重新编写，业务事实另行核对。

同一用户、同一公司品牌的演示文稿沿用所附公司标识。涉及其他单位或明确品牌要求时使用相应标识。14 页为参考稿页数，新任务页数由需求决定。

## 固定视觉规则

- 画面：16:9，1280 × 720 设计坐标。封面沿用绿色立体圆环背景，内页沿用浅绿色城市网络背景，背景始终在内容后方。
- 字体：微软雅黑。设计坐标字号：主标题 32，分区标题 25–29，正文 22–25，说明 20–22；封面主题 64、会议名称 46。适配实际版面时保持层级与可读性。
- 色彩：主绿 `#008C50`、标题深绿 `#075B2C`、正文 `#1A2B22`、浅薄荷 `#E7F6F0`、边线 `#B5E2D3`、黄 `#F4AC00`、浅黄底 `#FFF8E6`、内容底 `#F9FDFC`。
- 页眉：左侧标题，右侧公司标识，沿用原背景的页眉分隔线；内容从 y≈90 开始，横向边距约 52。
- 构成：办公人物场景配合立体文档图标，绿色分区标题条，浅绿细边容器，黄色序号与流程箭头。分区按内容组织，保留插画与文字之间的空间。
- 页底：单条结论或使用条件，使用深绿色文字与浅底容器；右下角页码。避免重复堆叠说明。

## 参考页与可编辑要求

本家族于 2026-10-08 补充了 [15 种扩展版式与素材库](rich-layout-library.md)。原默认稿提供背景、标识与既有可编辑页；扩展库提供中心辐射、任务流程、界面解读、指标对比、技术架构、规则、异常处理和派生版式。新稿按本页内容选择组合，详见 [内容组织与材料充实](content-richness.md)。

制作前查看 `../assets/default-illustrated/previews/` 中对应页面，并检查可编辑的 `reference.pptx`。

| 内容类型 | 参考稿页码 | 组织方式 |
| --- | --- | --- |
| 封面 | 1 | 左侧主题和辅助信息，右侧立体圆环 |
| 需求与任务 | 2 | 左侧人物与任务，右侧三条图标说明 |
| 分工与阶段 | 3、8、13 | 三列插画、标题、正文及底部提示 |
| 应用场景与指标 | 4、11 | 两行两列的内容分区 |
| 业务流程与架构 | 5、10 | 横向原生步骤框、序号、插画和箭头 |
| 内容与依据 | 7、12 | 原生表格，绿色表头与交替浅色行 |
| 讨论收尾 | 14 | 人物场景与三项讨论内容 |

文字、表格、序号、步骤节点与连接关系保持原生可编辑。背景、标识和插画使用所附 PNG，保持比例。序号与图标分别留位，检查图片矩形范围，避免图片底色遮住序号。正文换行按语义断句，检查单字成行与文字溢出。

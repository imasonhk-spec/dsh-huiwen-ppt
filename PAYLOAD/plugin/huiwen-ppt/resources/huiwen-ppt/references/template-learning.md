# 模板学习

1. 运行 `register` 保留参考并提取结构。`manifest.json` 初始状态为 `draft`。
2. 用 `render` 生成全部页面 PNG，检查每页及母版中的重复元素。仅看第一页无法判断全套模板。
3. 对 `inspection.json` 中的主题、直接指定字体、字号、颜色、母版和版式进行归纳。直接样式统计不是有效继承样式的完整结果，需结合渲染图核对。
4. 在模板目录保存 `visual-rules.md`，写明固定元素、可调整区域、版式容量、标题和正文层级、图片与图表规范。源文件缺字体时记录实际字体问题，不把软件替代字体自动写成规范。
5. 在模板目录保存 `expression-rules.md`，说明标题表达、信息密度、章节组织和论证习惯。区分原内容的写作惯例与需修正的事实或表述。
6. `knowledge-candidates.json` 保存页级候选文本和来源。排除隐藏对象及被整页图片覆盖的旧模板文字。整页图片中的业务内容从渲染图核对、识别和整理，标记提取方法与需重建的可编辑结构。整理为独立事实：来源、页码、时间、适用范围、确认状态。文件修改时间和所在文件夹日期不能代替事实日期。
7. 展示预览和规则，请用户校正。确认视觉与表达规则后执行 `approve-template`。知识项另行批准，只有已确认项进入正式知识库。

不同模板各自保留版本。修改当前项目不会自动更新参考。新增布局用于当前文件的批准不等于可永久收入模板库。

用户明确要求更新技能模板并供后续 PPT 使用时，按该要求登记长期保存与复用授权，保留原话、日期和适用范围。现有工具的 `approved` 表示已获模板复用许可；另以 `user_visual_acceptance` 记录新参考页的实际视觉验收。尚未查看成稿的用户保持 `not_yet_recorded`，制作与检查状态按实际记录。业务事实仍独立确认。

学习 PDF 视觉参考时保留原 PDF 和逐页预览，记录来源页和校验值；可编辑对象需重建，不声称恢复原母版或原始对象。独立风格建立独立素材目录与 catalog，说明共享的内容结构及隔离的视觉规则。新分支的选择与融合遵循 [风格选择与融合](style-selection.md)。

# 视觉参考与修订

用于用户给出截图、示例页，或要求调整现有 PPT 风格的续作。

先查看参考图与当前页。把参考图复制到项目 `assets/`，记录来源会话、用户原话、日期、SHA256 和适用范围。临时附件路径只作来源记录，后续制作使用项目中的副本。

将观察写入项目设计记录：标题与正文层级、左右或上下分区、插画形式、强调色、容器与连接关系、页底说明。区分用户明确保留的背景和标识、允许调整的布局，以及制作时的设计判断。只继承有授权的业务内容；参考图中的产品能力和效果数据需另行核实。

复用图片中的插画时，裁切范围须避开正文、序号和边框，检查裁切分辨率及背景色边缘。正文、序号、表格和流程节点使用原生对象。图片与序号分别预留位置，检查插画矩形范围及图层顺序，防止图片背景遮挡文字。用户要求插画风格时，检查人物、图标及版面层级与参考的对应关系。

用户最新要求改变风格时，及时更新 `brief.json` 和 `plan.json`，记录被替代的样式及仍有效的内容决定。已授权继续整套制作时，完成审阅稿；将用户视觉确认单独保留为实际状态。项目特定颜色和插画偏好记录在项目内，永久模板规则按用户另行确认入库。

每次修订保存新文件，核对页数、原生对象、背景与标识，并实际渲染。逐页查看；文字密集页、流程页和图片附近序号按可读尺寸复核。导入画布后核对当前文件及渲染报告的 SHA256，并记录已检查页码、具体修正与仍待确认事项。操作步骤见 [操作参考](operations.md)。
